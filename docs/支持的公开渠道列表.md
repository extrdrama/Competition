## 渠道明细

### 代码托管平台

#### `github` — GitHub 代码托管平台

通过代码搜索 API、仓库树遍历、公共事件流与公开 Gist 四个子通道检索公开仓库中的凭据泄露。

- 令牌要求：需要（未配置时该渠道自动跳过）
- 调用频率上限：24 次/分钟（代码强制限速）
- 平台主页：https://github.com

#### `gitee` — Gitee 代码托管平台

通过 Gitee 开放 API 的代码搜索接口检索公开仓库中的凭据泄露。

- 令牌要求：需要（未配置时该渠道自动跳过）
- 调用频率上限：20 次/分钟（代码强制限速）
- 平台主页：https://gitee.com

#### `gitlab` — GitLab（含自建实例）

通过 GitLab Blob 搜索 API 检索公开项目中的凭据；修改 GITLAB_BASE_URL 后即可覆盖企业内部自建 GitLab 实例。

- 令牌要求：需要（未配置时该渠道自动跳过）
- 调用频率上限：20 次/分钟（代码强制限速）
- 平台主页：https://gitlab.com

### 容器镜像

#### `container_registry` — 容器镜像仓库

拉取公开镜像的配置 blob 与文件系统层，检测构建历史（ENV/ARG 残留）与层内配置文件中的凭据；支持 Docker Hub 与兼容 Registry V2 API 的私有仓库。

- 令牌要求：不需要
- 调用频率上限：20 次/分钟（代码强制限速）
- 平台主页：https://hub.docker.com

### 包仓库

#### `npm_registry` — npm 包仓库

检索 npm 公开包并下载 tarball，检测误打包进发布包的配置与凭据文件；支持按关键词搜索最新发布的包。

- 令牌要求：不需要
- 调用频率上限：20 次/分钟（代码强制限速）
- 平台主页：https://www.npmjs.com

#### `pypi_registry` — PyPI 包仓库

通过 PyPI 最近更新榜单与指定包名拉取源码分发包（sdist），检测误打包的 .env / 凭据配置。

- 令牌要求：不需要
- 调用频率上限：20 次/分钟（代码强制限速）
- 平台主页：https://pypi.org

### 公开分享与代码片段

#### `paste_site` — 公开 Paste 分享站点

扫描 Pastebin、Ghostbin、Hastebin 等公开 Paste 服务的最新公开列表，检测其中的凭据泄露。仅访问公开页面。

- 令牌要求：不需要
- 调用频率上限：12 次/分钟（代码强制限速）
- 平台主页：https://pastebin.com

### Wiki 与知识库

#### `mediawiki` — Wiki / MediaWiki 站点

通过 MediaWiki 标准 api.php 搜索接口检索公开 Wiki 页面，检测页面内容中粘贴的配置片段与凭据。

- 令牌要求：不需要
- 调用频率上限：30 次/分钟（代码强制限速）
- 平台主页：https://www.mediawiki.org

通过 Confluence REST 搜索接口检索公开空间页面，检测运维文档、部署手册中粘贴的明文凭据。

- 令牌要求：需要（未配置时该渠道自动跳过）
- 调用频率上限：20 次/分钟（代码强制限速）
- 平台主页：https://www.atlassian.com/software/confluence

- 令牌要求：不需要
- 调用频率上限：15 次/分钟（代码强制限速）

#### `telegram` — Telegram 公开频道

扫描公开 Telegram 频道的网页预览（t.me/s/<频道>），检测其中张贴的配置、数据库 dump 与脚本中的凭据泄露。仅访问公开预览页，不登录、不使用 Bot API。

- 令牌要求：不需要
- 调用频率上限：10 次/分钟（代码强制限速）
- 平台主页：https://t.me

### 自托管与公告

#### `rss_feed` — RSS/Atom 订阅源

通用 RSS/Atom 订阅渠道：在配置中填入任意数量的订阅源（技术博客、安全公告、邮件列表归档等）即可纳入监控，检测博客与公告中误贴的凭据。仅获取站点主动发布的公开 feed。

- 令牌要求：不需要
- 调用频率上限：30 次/分钟（代码强制限速）

#### `search_engine` — 通用搜索引擎定向检索

以 site: 语法对难以直接接入的站点做定向补充检索，需要配置可用的搜索 API 端点；未配置时该渠道自动跳过。

- 令牌要求：需要（未配置时该渠道自动跳过）
- 调用频率上限：10 次/分钟（代码强制限速）

### App 与小程序

#### `mobile_app` — 移动应用安装包（APK）

解包公开下载的 APK/AAB 安装包，扫描 assets、资源文件、Manifest 与 dex 中的可见字符串；本机存在 jadx 时自动反编译以提升命中率。

解包微信小程序分包文件，扫描其中的 JS 业务代码与 JSON 配置，检测硬编码在小程序端的第三方密钥与后台地址。

- 令牌要求：不需要
- 调用频率上限：30 次/分钟（代码强制限速）

### 本地与企业内网

#### `local_dir` — 本地/内网目录

递归扫描指定目录中的源码、配置、脚本与归档文件，适用于企业内网自查与离线演示场景。

- 令牌要求：不需要
- 调用频率上限：100000 次/分钟（代码强制限速）

## 扩展方式

新增一个渠道只需三步，无需改动任何现有代码：

```python
@registry.register
class MySource(SourceAdapter):
    meta = SourceMeta(
        name="my_source", label="我的渠道", category="内容共享平台",
    )

    def discover(self, cursor=None):
        ...  # 产出 RawDoc
```

1. 新建模块并在类上标注 `meta`；
2. 用 `@registry.register` 装饰；
3. 在 `credwatch/sources/__init__.py` 中增加一行 import。

`normalize()`（内容归一化、归档与镜像层解包）与 `next_cursor()`（增量游标）已由基类提供默认实现，绝大多数渠道无需覆写。
