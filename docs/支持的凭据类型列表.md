## 规则语法说明

规则以 YAML 描述，单条规则字段如下：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 规则唯一标识 |
| `name` | 是 | 人类可读的凭据名称 |
| `kind` | 是 | 凭据类型（用于类型统计） |
| `severity` | 是 | 风险等级：critical/high/medium/low |
| `pattern` | 是 | Python 正则 |
| `secret_group` | 否 | 指定哪个捕获组才是密钥本身（连接串类必填，否则会把用户名当凭据） |
| `require_keywords` | 否 | 关键词必须邻近共现，用于压制泛化规则的误报 |
| `validator` | 否 | 关联的只读活性验证器 |
| `multiline` | 否 | 按行匹配（`^`/`$`） |
| `keywords` | 否 | 检索关键词，供渠道查询构造使用 |
| `description` | 否 | 风险说明 |
